阿斯图系列卫星接收、解码与遥测上传套件
By BG7ZDQ

1.5.0 起，启动器、解码器和独立卫星跟踪窗口会读取操作系统语言。中文系统
使用简体中文，日文系统使用日文，其他系统统一使用英语。翻译包位于
decoder\translations\，可在不重新编译主程序的情况下更新。安装向导提供中文、
英语和日语。安装向导每次启动均由用户选择语言，不按系统语言自动决定。

启动接收前可选择“同时上传至 SatNOGS”。该选项只上传实时解码成功的 FEC 帧，
播放历史录音时不会上传。请确保计算机时间、呼号和地面站经纬度准确。

安装程序可选安装 SDR# Studio 遥测预设版。SDR# 中加入 ASRTU 系列及相关卫星的
频点、接收模式、带宽和布局预设。SDR# 与 Airspy 的权利归原权利人所有；
本套件与 Airspy 无隶属、赞助、认可或官方合作关系。详见安装目录中的
SDRSHARP_NOTICE.txt。启动器内置基于 SGP4 的卫星跟踪与多普勒控制，
可选择卫星、自定义标称下行频率，并按顺序从多条 TLE 地址下载和回退。
解码器、上传代理和独立多普勒窗口分别使用易辨认的经典 Windows 像素图标；
启动器继续使用阿斯图系列卫星徽标。
启动器中的声卡选择标签简化为“声卡”；隐藏不适用的声卡选项时会完整收起
该表单行；启动按钮与上传代理按钮
保持顶部对齐。所有下拉框显示固定箭头提示。解码器星座图会随画布比例动态调整
坐标范围，使 I/Q 两轴单位刻度始终保持相同的屏幕比例。

桌面上的“阿斯图系列卫星启动器”用于配置并启动：
1. 阿斯图系列卫星 C++/Qt 接收解码器
2. proxy_mmt_gui 遥测上传代理

安装 SDR# 组件时，启动器依次提供“本地内存共享 RAW 模式 I/Q 桥接”、
“立体声零中频 RAW 模式 I/Q 输入”和“单声道实数域 12KHz 电台 IF 输入”；
未安装 SDR# 组件时不显示第一项，仅提供后两种声卡输入。
安装 SDR# 组件时，“阿斯图系列本地 I/Q 与多普勒”插件会通过本地共享内存
读取内置跟踪器的目标频率；插件面板可随时开启或关闭自动多普勒调谐。
内置频率预设包括 AO-123 的 435.400 / 436.210 MHz、BY04 的
437.443 MHz，以及 JAMX 的 435.500 / 435.075 MHz。
单声道实数 IF 的瀑布图与输入频谱直接连接原始 float 流并仅显示正半谱，
以 12 kHz IF 为图中的 0 Hz；该显示支路位于 I+j0 转换和解调混频之前。
“启动接收”和“启动上传代理”为两个独立按钮，
可只进行本地接收、解码、录音和日志保存，也可按需单独打开上传代理。

上传目标可选择：
- ASRTU-1 -> ws://1.92.100.130:9000
- BY-04uv -> ws://119.45.229.166:9000

安装时只填写呼号、经度、纬度和海拔。卫星在每次点击“启动上传代理”时弹窗
选择，启动器也可随时修改地面站资料。点击“启动接收”只打开接收程序；
点击纯文字的“启动上传代理”按钮打开 MMT 上传代理，启动器保持打开。

解码器与代理分别保存在 decoder 和 proxy 子目录，避免运行库冲突。
启动器可按次启用或关闭 48 kHz/16-bit WAV 自动录制（I/Q 模式为双声道，实数中频
模式为单声道），并可选择任意支持的声卡及快速播放录音文件。录音和完整解码日志
按时间戳保存在安装目录的 ASRTU1_Records 子目录中，
可通过启动器的“打开录音与日志”按钮访问。上传代理会打开独立的
黑色控制台窗口，连接和上传状态直接显示在该窗口。proxy.log 只记录启动时间、
PID 和启动检查结果，不再重定向 ncurses 画面，因此不会出现 ANSI 控制码。
若代理立即退出，启动器会显示退出代码。套件内附代理所需的 xterm 终端描述。

decoder.log 每秒保存一次界面所用的 GNU Radio SVR SNR 估计值；每个成功 FEC
帧以 GNU Radio Message Debug 风格完整保存全部 223 字节，不再截断为前 64 字节。
本地内存共享 RAW 模式 I/Q 桥接连续 0.5 秒没有新样本时，SNR 曲线显示为空缺，SNR 与
环路频偏不再沿用旧值，同步状态切换为 NOSYNC；样本恢复后自动继续。

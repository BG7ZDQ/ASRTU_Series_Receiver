# SDR++ Linux payload

`sdrpp_ubuntu_jammy_amd64.deb` is the Ubuntu 22.04 x86_64 SDR++ nightly package
used by the optional Linux installer. It is installed only when the user selects
the SDR++ option in `setup.sh`.

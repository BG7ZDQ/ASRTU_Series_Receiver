# Assets

- `branding/` contains the launcher logo and its Windows icon form.
- `icons/` contains application-specific DSP, proxy, and Doppler icons.
- `ui/` contains small interface resources such as the combo-box arrow.
- `translations/` contains editable Qt translation sources and compiled language packs.

Keep generated screenshots and temporary icon previews in ignored `outputs/`; only source assets and files consumed by the build belong here.
